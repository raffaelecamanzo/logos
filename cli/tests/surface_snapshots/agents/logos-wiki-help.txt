Source wiki: write/read/search/status/delete agent-generated pages in the gate-immune `.logos/wiki.db` store (CR-008). Every read carries mandatory provenance (generator, written-at HEAD, per-anchor freshness, the fixed generated-content marker)

Usage: logos wiki [OPTIONS] <COMMAND>

Commands:
  write        Upsert a page by slug: byte-verbatim body (1 MiB cap), write-time anchor resolution, mandatory generator label (FR-WK-02)
  read         Read a page by slug with mandatory provenance + per-anchor freshness (FR-WK-04). A miss (or an all-anchors-gone auto-prune) exits non-zero
  search       FTS5 bm25 search over page titles + bodies, staleness-flagged (FR-WK-05)
  status       Store summary + regeneration work-list: stale, missing-anchor, pruned, and page-worthy entities without a page (FR-WK-06)
  generate     Format the `wiki status` work-list into an ordered, offline generation queue (FR-WK-13): a human-readable prompt block by default, or `--json` for machines. Each item carries its target slug and a runnable `wiki write` skeleton. A pure read — no `wiki.db` write, no LLM, no network
  materialize  Deterministically assemble the presented tier (FR-WK-20, ADR-57): in SRS mode, present each Design/Specs category (and the single-file Architecture page) from the project's authored `docs/specs/**` sources into `wiki.db` with `generator = "logos:doc-present"`, then run the reconciliation sweep. A pure deterministic write — no LLM, no network (NFR-SE-01); byte-identical on re-run. Outside SRS mode (Case 2) this is a no-op. Run automatically by the UI-gated generation flow ahead of the LLM queue (FR-WK-18); safe to run manually
  delete       Explicitly delete a page by slug (FR-WK-07); an unknown slug exits non-zero
  skill        Materialize the embedded wiki-generation skill (FR-WK-08): the canonical `.agents/skills/logos-wiki/` directory plus the `.claude/skills/logos-wiki` symlink. Refreshes an existing install or a post-upgrade skill. CLI-only
  help         Print this message or the help of the given subcommand(s)

Options:
      --project <PATH>  Override the project root (defaults to the current directory)
      --json            Output results as machine-readable JSON
      --quiet           Suppress non-essential output (exit codes and --json still apply)
  -h, --help            Print help
