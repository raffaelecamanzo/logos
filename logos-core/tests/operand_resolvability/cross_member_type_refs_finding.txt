WHAT THIS FINDING DOES NOT ESTABLISH
------------------------------------

  - CRA-01 (Avro-generated classes keep the schema's namespace + name): validated at
    configuration level only. The four `*-kafka-models` members holding `.avsc`
    (archive, filters, mailbox, official-log) configure `avro-maven-plugin` with
    `goal schema` and `sourceDirectory src/main/resources`, no template or namespace
    override — the plugin default. No Maven build was run, so the 140 Avro-backed
    Reach triples rest on that default.
  - These rows are the estate as indexed by logos 1.5.0, before S-465 rekeys Java
    modules by package. S-465 binds intra-member imports (the self-owned rows); a
    cross-member import cannot bind inside its member, so the exactly-one population
    is not expected to move, but it was not re-measured after S-465.
  - The harness's owner rule is its own (CR-152 section 7). The product's declared-
    type facts (S-472) must derive source names from S-465's package-shaped module
    key, not from this module.
